# Вавилонская галерея
Вся галерея — один статический файл index.html. Сервер не нужен: рендер, поиск, фильмы
и конвертация видео работают в браузере.

# Go-часть (необязательно)
go run main.go — локальный сервер, нужен для того чтобы видео перерабатывалось быстрее.


# Без запуска интерфейса
go run main.go -o out.png -seed 42 — картинка в файл.
go run main.go -video clip.mp4 -w 96 -every 5 -bpp 8 -o clip.png — быстрая конвертация больших видео через ffmpeg
(формат txt тот же, что делает веб-версия).
